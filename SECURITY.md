# Security Policy

## Project status

Deku Linux is in early planning. There are no supported releases at this time, and this policy does not imply a staffed response team or guaranteed response-time SLA.

## Reporting a vulnerability

Do not publish exploitable, unpatched vulnerability details in a public issue.

Use GitHub's **Report a vulnerability** feature if private vulnerability reporting is enabled. If it is unavailable, use a verified private contact method listed on the organization profile. Do not send unrelated personal data or secrets.

Where safe, include the affected component and revision, impact, reproduction steps, proof of concept, and possible mitigations. Allow reasonable time for investigation and coordinated disclosure. Do not access or modify data that is not yours.

## Security priorities

- Isolated, minimally privileged builds.
- Traceable package sources and reviewed dependency changes.
- Signed repository metadata and release artifacts.
- Protected signing keys with rotation and revocation procedures.
- Timely security updates and a documented end-of-life policy.
- Least-privilege CI permissions and pinned third-party workflow actions.
- Tested installation, upgrade, rollback, and recovery paths.

## Supported versions

No Deku Linux releases are currently supported. A support table will be published when releases exist.
